## What Is This?  
This is **ADHD 10 Key V2**, the second go at my custom numpad. It’s a mess of ADHD-driven tinkering because I’m too cheap to buy one. It works, it’s got RGB lights tied to NumLock, and it’s as basic as it gets. Good enough.

---

## Features  
- **NumLock RGB LEDs**: Lights change with NumLock—on, they’re alive; off, they’re dead.  
- **Sine-Wave Animation**: LEDs cycle colors when NumLock’s on. Looks cool, I guess.  
- **CircuitPython + KMK**: Runs on simple, hackable code.  
- **4x5 Key Grid**: Standard numpad layout—NumLock, Backspace, Enter, the works.  
- **Common Anode RGB**: Used what I had lying around. It works.

## Prerequisites  
You’ll need:  
- **CircuitPython Microcontroller**: Made for RP2040 boards (like a Pico).  
- **KMK Library**: For key scanning and HID. Get it [here](https://github.com/KMKfw/kmk_firmware).  
- **PWM Support**: For the RGB LEDs (common anode).  
- **Switches & Shit**: I used Cherry MX Browns—use what you’ve got, tweak debounce if it sucks.  

---

## Installation  
1. **Flash CircuitPython**: Load the UF2 file onto your board.  
2. **Add KMK**: Dump the library in `lib/`.  
3. **Copy Code**: Stick `code.py` from this repo on your board.  
4. **Wire It**: Match the pins in the code or fix it yourself.  
5. **Test It**: Plug it in, hit some keys, see if the lights work.

## Usage  
### RGB Lighting  
- **NumLock On**: LEDs run a sine-wave color cycle.  
- **NumLock Off**: Lights shut off. Done.  

### Key Layout  
Here’s the 4x5 setup:  
```
NLCK  /  *  ⌫
7     8  9  +
4     5  6   
1     2  3  ⏎
      0  0  .
```  
Basic numpad—NumLock, operators, digits, double-wide zero.  

---

## Configuration  
- **Keymap**: Set in `code.py` with KMKKeyboard. Change the grid or pins if you want.  
- **Debounce**: Tuned for MX Browns. Adjust it if your switches are crap.  
- **RGB Shit**: Tweak the sine-wave code if you care.
