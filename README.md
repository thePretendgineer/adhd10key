## What Is This?  
Welcome to **ADD 10 Key V2**, the second iteration of my custom numpad project. Born from a mix of ADHD-fueled tinkering and a stubborn refusal to buy a pre-made solution, this little beast adds seamless functionality and mesmerizing RGB flair to any keyboard setup. It’s minimal, it’s chaotic, it’s got lights that vibe with your NumLock state—what more could you want?

---

## Features  
- **NumLock-Responsive RGB LEDs**: Lights shift dynamically based on NumLock status—on means a colorful party, off means nap time.  
- **Sine-Wave RGB Animation**: Smooth, hypnotic color transitions when NumLock is active. Think of it as a tiny disco for your desk.  
- **CircuitPython + KMK Powered**: Built with lightweight, hackable tools for maximum flexibility.  
- **4x5 Key Grid**: A compact, traditional numpad layout with all the essentials—NumLock, Backspace, Enter, and more.  
- **Common Anode RGB Support**: Because I had these LEDs lying around, and they work.  

---

## Project Overview  
This project started with a problem: my Das Keyboard 4 didn’t have a numpad, and I wasn’t about to shell out for a separate one. Enter **ADD 10 Key V2**—a DIY solution cobbled together from an RP2040 microcontroller, some Cherry MX Browns, and a 3D-printed case that’s... let’s call it "characterful" after the front fell off mid-build. It’s powered by CircuitPython and the KMK library, with RGB LEDs that sync to NumLock for that extra dose of visual feedback. Check out the full saga on my blog: [The Front Fell Off: An ADD-venture](https://pretendgineer.com/the-front-fell-off-an-add-adventure/).

## Prerequisites  
To get this running, you’ll need:  
- **CircuitPython-Compatible Microcontroller**: Designed for RP2040-based boards (e.g., Raspberry Pi Pico).  
- **KMK Library**: Handles the keyboard matrix and HID output. Grab it [here](https://github.com/KMKfw/kmk_firmware).  
- **PWM-Capable Board**: For those sweet RGB LED effects (common anode setup).  
- **Switches & Hardware**: I used Cherry MX Browns, but use what you’ve got—just tweak the debounce if needed.  

---

## Installation  
1. **Set Up CircuitPython**: Flash your board with the latest CircuitPython UF2 file.  
2. **Install KMK**: Drop the KMK library into your board’s `lib/` folder.  
3. **Copy the Code**: Grab `code.py` from this repo and slap it onto your board.  
4. **Wire It Up**: Follow the pin config in the code (or adjust for your setup).  
5. **Test It**: Plug it in, press some keys, and watch the lights do their thing.

## Usage  
### RGB Lighting  
- **NumLock On**: LEDs kick into a smooth sine-wave RGB animation.  
- **NumLock Off**: Lights go dark, signaling the numpad’s off-duty.  

### Key Layout  
Here’s the 4x5 grid:  
```
NLCK  /  *  ⌫
7     8  9  +
4     5  6   
1     2  3  ⏎
      0  0  .
```  
It’s a classic numpad setup—NumLock, operators, digits, and a double-wide zero because why not?

---

## Configuration  
- **Keymap**: Defined in `code.py` using KMKKeyboard. Tweak the 4x5 grid or pin assignments as needed.  
- **Debounce**: Set for Cherry MX Browns. Adjust the timing if your switches are chattier.  
- **RGB Tuning**: Mess with the sine-wave params in the code for faster/slower/different vibes.
